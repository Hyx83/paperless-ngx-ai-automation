# Version 4.2 – Mehrdeutigkeitslogik

## Problem

```text
Kaufland (Filiale 3970, Herford)
```

wurde wegen des Kommas als mehrdeutig eingestuft.

## Lösung

Klammerinhalte werden für die Mehrfach-Korrespondentenerkennung ignoriert.

Außerhalb von Klammern bleiben Kommata ein wichtiges Signal für mehrere Organisationen.
