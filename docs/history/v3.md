# Version 3 – konservatives Korrespondenten-Matching

## Schwerpunkt

Falsche Korrespondentenzuordnungen verhindern.

## Änderungen

- Fuzzy-Schwelle 0.93
- vorhandene Korrespondenten niemals automatisch überschreiben
- Konflikte explizit markieren
- Mehrfachorganisationen blockieren
- Substring-Matching begrenzen
- Einwort-Titel restriktiver behandeln
- Prompt stärker auf echten Aussteller/Absender fokussieren

## Typischer Regressionstest

```text
Stadt Porta Westfalica
```

darf nicht automatisch mit:

```text
Stadtwerke Porta Westfalica GmbH
```

verschmolzen werden.
