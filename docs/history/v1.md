# Version 1 – erster Batch-Prototyp

## Ziel

Vorhandene Paperless-Dokumente erstmals automatisch mit einem LLM analysieren.

## Funktionen

- Batch über vorhandene Dokumente
- Titelvorschlag
- Korrespondentenvorschlag
- Datumsanalyse
- Dry-Run
- CSV
- APPLY-Modus

## Problem

Die erste Version war noch zu vertrauensvoll gegenüber KI-Ausgaben.

Insbesondere Datumswerte konnten semantisch korrekt erkannt sein, aber trotzdem nicht dem gewünschten primären Paperless-Dokumentdatum entsprechen.

## Ergebnis

Die Version war ein erfolgreicher technischer Machbarkeitsnachweis, aber noch kein sicherer Dauerbetrieb.
