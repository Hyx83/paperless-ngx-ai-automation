# Version 4.1 – zweite KI-Verifikation

## Problem

Ein einzelner KI-Korrespondent kann plausibel, aber trotzdem falsch sein.

## Lösung

Neue oder neu zu setzende Korrespondenten werden durch einen zweiten separaten LLM-Aufruf geprüft.

## Verifikationsfragen

Nicht bestätigen, wenn der Kandidat nur:

- erwähnt wird
- Empfänger ist
- Gerätehersteller ist
- Vertragspartner ist
- in einer Anlage steht
- OCR-fehlerhaft wirkt

## Zusätzlich

- atomisches Speichern
- geschützte Titel bleiben vollständig unangetastet
- APPLY-Neuanlage korrekt als Änderung behandeln
